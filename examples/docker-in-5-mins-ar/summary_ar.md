**ملخص الفيديو: لماذا نحتاج Docker وكيفية استخدامه**

- تشغيل الكود على جهازك قد يعمل بدون مشاكل، لكن عند نقله إلى جهاز آخر قد يواجه أخطاء بسبب اختلاف إصدارات الأدوات (مثال: Node 18 على جهازك vs Node 14 على الجهاز الآخر).  
- اختلاف نظام التشغيل (مثال: من Windows إلى Linux) يزيد من تعقيد المشكلات ويولد أخطاء إضافية.  
- الحل الأول هو استخدام **Virtual Machine (VM)** حيث تُحزم نظام التشغيل وكل المتطلبات داخل حزمة واحدة (VM Snapshot)، لكن هذه الحزم ثقيلة الحجم وتستهلك موارد كثيرة.  
- **Docker** هو الحل المثالي: يخلق حزمة خفيفة (Docker Image) تحتوي فقط على التطبيق والكود دون الحاجة لنظام تشغيل كامل، وتُشغل داخل حاوية (container) تعمل على أي جهاز بوجود Docker Engine فقط.  
- لاستخدام Docker يجب تنزيله من الموقع الرسمي Docker.com وفق نظام التشغيل (مثال: Docker for Windows).  
- لإنشاء صورة Docker تحتاج إلى ملف **Dockerfile** داخل مشروعك يحدد الأوامر لبناء الصورة وإضافة ملفات المشروع (مثل server.js أو index.js).  
- بعد كتابة Dockerfile تُنفّذ الأمر `docker build` في الطرفية لإنشاء Docker Image.  
- لتشغيل الحاوية يمكنك إما الضغط على زر “Play” في الواجهة أو استخدام الأمر `docker run -it` في الطرفية.  

**الخلاصة:** Docker يضمن تشغيل التطبيقات بنفس الطريقة على أي جهاز دون مشاكل الإصدارات أو أنظمة التشغيل.
